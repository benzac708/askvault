How this answers

Retrieval is lexical: SQLite FTS5 with BM25 ranking over the section text. There are no embeddings and no vector store, so a question that shares no words with a passage will not find it even when it means the same thing.

The model sees only the passages listed under each answer. If nothing matches, the reply says so instead of guessing — a wrong answer with a citation is worse than no answer.

Served by one replica behind Traefik, deployed by Argo CD, instrumented with Prometheus — /readyz reports index state.
